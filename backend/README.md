# MillTrack — Backend API Service

REST API Service for Mill Management and Samples Monitoring built with Go Fiber v2, GORM, and PostgreSQL.

## 🚀 Quick Start

1. **Environment Setup:**
   ```bash
   cp .env.example .env
   # Configure database credentials in .env
   ```

2. **Download Dependencies:**
   ```bash
   go mod download
   ```

3. **Run Application:**
   ```bash
   go run main.go
   ```

## 📖 API Documentation (Swagger)
- Interactive Swagger UI: `http://localhost:3000/swagger/index.html`
